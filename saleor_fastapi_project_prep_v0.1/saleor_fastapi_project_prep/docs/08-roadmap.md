## 推荐开发顺序

先让一个垂直业务切片跑通，再扩展模块。例如：

`注册/登录 -> 管理员创建商品和 SKU -> 入库 -> 用户加购 -> 结算 -> 下单 -> 模拟支付 -> 查询订单`

不要先把所有表建完再开始写业务；数据库设计允许在迁移管理下迭代演进。
